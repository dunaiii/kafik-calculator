# Калькулятор кафіка

Невеликий адаптивний калькулятор погодинної ставки із зарплати, кількості годин та додаткового коефіцієнта. Інтерфейс українською, без сторонніх бібліотек. Працює як PWA і може бути доступний офлайн після першого відвідування через HTTPS.

## Як користуватися

Введи **зарплату з коефіцієнтом**, **відпрацьовані години** та **коефіцієнт** (наприклад, 1,05 або 1.05). Підрахунок відбувається автоматично. Можна натиснути «Скинути», щоб повернути прикладні значення.

Формули:

- **Зарплата без коефіцієнта** = зарплата / коефіцієнт
- **Базовий кафік** = зарплата без коефіцієнта / години
- **Кафік з коефіцієнтом** = зарплата / години
- **Зміна за годину** = кафік з коефіцієнтом − базовий кафік
- **Зміна зарплати** = зарплата − зарплата без коефіцієнта
- **Зміна у відсотках** = (коефіцієнт − 1) × 100%

Суми відображаються в тій самій валюті, у якій введено зарплату. Значення округлюються **лише для показу**; у формулах використовується повна точність.

## Запуск і тести

Для перегляду локально запусти статичний сервер у корені репозиторію (ES-модулі не завантажуються через file://):

~~~sh
python -m http.server 8000
~~~

Потім відкрий http://localhost:8000. Для автоматичних тестів:

~~~sh
deno test
~~~

Під час оновлення офлайн-файлів збільшуй версію CACHE_NAME у sw.js, щоб користувачі отримували нову версію застосунку.
